# 概述
check_zombie.sh 是一个用于检查虚拟化环境中 QEMU 僵尸进程和孤儿进程的脚本。它可以帮助管理员识别无效的 QEMU 进程，避免宿主机资源泄漏、CPU/内存占用异常等问题，保障虚拟化环境稳定运行。

# 功能
检查QEMU僵尸进程：
- 遍历所有QEMU相关进程，检测状态为僵尸（Z）的进程。
- 如果发现僵尸进程，记录错误信息。

检查QEMU孤儿进程：
- 校验每个QEMU进程对应的虚拟机是否处于运行状态。
- 如果QEMU进程无对应运行虚拟机，记录错误信息。

检查QEMU进程合法性：
- 识别无虚拟机名称标识的异常QEMU进程，记录警告信息。
- 过滤无效进程，提升检查准确性。

统一日志输出：
- 输出格式与 VMAnalyzer 其他脚本保持一致。
- 包含 info、warning、error 三种级别日志。

# 使用方法
1. 运行脚本
在终端中执行以下命令来运行脚本：

sudo bash check_zombie.sh

2. 查看日志
脚本执行完成后，日志文件会生成在 /var/log/vmanalyzer/ 目录下，文件名为 zombie_qemu_check-<时间戳>.log。

日志文件包含以下内容：

正常信息：标记为 info，记录检查过程中的详细信息。
警告信息：标记为 warning，记录无虚拟机名称的异常QEMU进程。
错误信息：标记为 error，记录僵尸QEMU进程、孤儿QEMU进程。

3. 检查结果
如果脚本发现错误或警告，日志文件中会记录相关信息，并在脚本结束时输出数量。
如果未发现风险，脚本会输出 Check completed successfully. No errors found.。
